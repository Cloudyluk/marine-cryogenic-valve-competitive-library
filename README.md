# 船用低温阀门竞争产品选型库

用于整理国内外船用低温阀门的公开竞争产品资料，并按品牌、型号/系列、阀型、工况、低温能力与船级社资料进行初步筛选和对比。

## 本地运行

```bash
npm install
npm run dev
npm run build
```

## 数据维护

竞品资料位于 [src/data/competitors.ts](src/data/competitors.ts)。每条记录必须带有品牌、`model`（公开产品名称或公开产品系列）、公开来源链接、核验日期和资料状态。

- `公开证实`：公开来源可直接支持的描述。
- `公开资料推断`：根据公开资料做出的有限推断，必须写明待核实项。
- `待厂家确认`：公开资料没有提供，不能填入推测参数。

本网站是竞争情报与初步选型工具，不是报价单、认证数据表或性能保证。采购、设计和船级社送审时，应以项目数据表、船级社认可和单阀证书为准。

## GitHub Pages

将仓库的 Pages 发布源设置为 **GitHub Actions**。推送到 `main` 分支后，`.github/workflows/deploy-pages.yml` 会构建并部署 `dist` 目录。
