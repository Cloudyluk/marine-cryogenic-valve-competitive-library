# 官方资料逐项完善设计

## 目标

将船用低温阀竞争产品资料库中每条“待厂家确认”字段逐项核验；仅采用制造商官网页面、制造商发布的数据表、说明书或官方公告作为写入依据。

## 范围与边界

- 覆盖现有所有品牌和产品记录，不删除已有已核验资料。
- 优先完善具体产品名称；泛系列或方案记录只能在找到官方可对应的具体型号后拆分并补参。
- 不采用经销商页面、行业目录、搜索摘要、论坛、项目新闻或推断作为参数依据。
- 厂家官网没有公开的字段保留“待厂家确认”，并在说明中明确缺少的是型号数据表、订货规格书或证书。
- 认证字段只记录官网明确列出的证书、标准或批准；不能把产品符合某项设计标准写成船级社型式认可。

## 字段验收规则

每个产品字段均须由其 `sources` 中至少一条官方链接支持：

| 字段 | 可写入条件 |
| --- | --- |
| 最低温度 | 产品页或数据表明确给出温度范围/最低温度 |
| 压力、口径、端连接 | 同一具体产品或明确产品系列的公开范围 |
| 材料、结构、附件 | 产品页或数据表直接列示 |
| 标准/认证 | 产品页、数据表或厂家证书页直接列示 |
| 船级社 | 厂家官网明确列出船级社名称、证书或适用型号 |

## 执行批次

1. 具体型号：补齐压力、口径、端连接、结构、材料、标准与附件。
2. 船级社：核验各型号的 CCS、DNV、ABS、LR 等认可及其适用范围。
3. 泛系列与方案：以官方数据表拆分为具体型号；无法拆分则保留泛系列与待确认字段。
4. 每批写入后：运行数据测试、生产构建、差异检查并发布 GitHub Pages。

## 可验证结果

- 每个新增或修改字段均能从页面的“官方资料”外链追溯。
- 所有剩余待确认字段可在备注中看到缺失资料类型。
- 产品比较仍始终显示品牌和型号。
