# 船用低温阀门竞争产品选型库：完整工作流设计

## 目标

将现有单页产品清单扩展为同一站点内连通的“选型 + 情报”资料库。用户既能以工况和参数初选产品，也能从品牌主体、产品族、工厂和市场分布研判竞争态势；任何公开证据都可从页面跳转至相应竞品官网或官方资料。

## 信息架构

站点保留统一的深蓝专业风格和响应式布局，顶部导航切换四个工作区：

1. **选型库**：默认入口。提供全局关键词搜索和现有多维筛选；结果表保留品牌和型号/系列，支持排序、查看详情和加入对比。
2. **对比中心**：承接已选择的产品，固定显示品牌与型号，并以关键参数矩阵呈现差异。用户可删除条目、清空列表、返回产品详情或直接打开每条来源。
3. **品牌情报**：按地区与关键词浏览所有在库品牌；每张品牌档案显示公司主体、总部、制造信息、产品族、LNG/海事定位、市场覆盖、核验时间与说明。
4. **标准索引**：按低温基础、LNG/船用、阀门型式、测试/认证分类展示。每条标准说明其在选型或验收中的作用，并明确实际适用性取决于项目规格书与船级社要求。

## 核心交互

- 顶部搜索同时匹配品牌、型号/系列、阀型、应用与介质；清除后恢复默认结果。
- 选型库的筛选、搜索和排序共同生效，结果数量实时更新；无结果时给出清晰的重置入口。
- 对比最多保留四个产品，任何对比项都必须展示“品牌 · 型号/系列”。对比中心以相同字段顺序展示最低温度、压力、口径、连接、结构、附件、标准、船级社、证据等级和最后核验日期。
- 产品详情链接到品牌档案；品牌档案可继续打开官网、产品页或官方 PDF。
- 所有外部链接均在新标签页打开，使用来源标签作为链接文字，并标明这是厂商公开资料；没有可公开确认的链接时，不生成空按钮。
- 对比数据保持在浏览器本地会话中，切换工作区不丢失。

## 数据与证据规则

- 现有 `ValveSeries` 与 `BrandProfile` 是唯一数据源；页面不引入未经来源支持的新参数或市场结论。
- 产品级参数、公司级能力与项目认证严格分层。公司公开能力范围不能写成单一产品型号的额定值。
- `公开证实`、`公开资料推断`、`待厂家确认` 继续在结果、详情和对比中心可见。
- 品牌情报不将贸易主体、关联方或方案供应商误标为自有阀门工厂；此类关系必须在说明中保留边界。
- 标准索引仅作为选型提示，不表示任一产品自动符合该标准或取得船级社认可。

## 组件与状态边界

- `App` 负责当前工作区、筛选/关键词/排序和对比选择状态。
- `LibraryView` 组合搜索、筛选、结果表和空状态；`CompareView` 负责参数矩阵；`BrandDirectoryView` 负责品牌列表与品牌档案入口；`StandardsView` 负责索引内容。
- 产品详情、品牌档案继续使用可关闭的对话框；对话框内的来源统一经安全外链组件渲染。
- 纯筛选、排序、比较与数据映射逻辑放在 `lib` 中，以便独立测试。

## 验收条件

- 导航可在四个工作区间切换，且当前工作区状态清晰。
- 搜索、筛选、排序、无结果重置、产品详情、品牌档案、加入/移除/清空对比均可实际操作。
- 对比中心每一个条目都显示品牌和型号/系列；矩阵显示完整关键字段。
- 每一项有公开来源的产品或品牌均可从详情/档案打开至少一个有效的官网或官方资料链接；链接新标签打开。
- 桌面和手机视图均无横向内容截断，表格/对比矩阵可读。
- 增加针对核心交互与外链呈现的测试；全部测试、类型检查和生产构建通过。
